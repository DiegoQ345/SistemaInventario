# Documentación del Sistema de Inventario

Esta carpeta contiene toda la documentación técnica, análisis de arquitectura, registros de compilación y notas de desarrollo del proyecto.

## 📋 Propósito

Almacenar y organizar:
- **Documentación de arquitectura**: Análisis de sistemas MVVM, componentes, servicios
- **Logs de compilación**: Registros históricos de builds y errores
- **Guías de desarrollo**: Procedimientos de instalación, distribución y fixes aplicados
- **Análisis técnicos**: Estudios de flujos de impresión, DPI, diseño de tickets

## 📁 Contenido

### Arquitectura y Diseño
- `ARQUITECTURA.md` - Visión general de la arquitectura del sistema
- `MVVM_ARCHITECTURE.md` - Patrón MVVM implementado
- `COMPONENTS_SYSTEM.md` - Sistema de componentes reutilizables
- `NOTIFICATIONS_ARCHITECTURE.md` - Sistema de notificaciones
- `SALES_CART_SYSTEM.md` - Sistema de carrito de ventas

- `TICKET_DESIGN_ANALYSIS.md` - Análisis de diseño de tickets
- `TICKET_DESIGN_FIXES.md` - Correcciones aplicadas al diseñador

## 🔧 Mantenimiento

Los archivos en esta carpeta se actualizan durante el desarrollo para:
1. Documentar decisiones arquitectónicas
2. Registrar problemas y sus soluciones
3. Mantener historial de cambios importantes
4. Facilitar onboarding de nuevos desarrolladores
